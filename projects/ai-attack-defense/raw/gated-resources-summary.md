## What is NOT gated (recap, so the contrast is visible)

Everything needed to run a paired VI/EN test of a shipping-guardrail *product* against Vietnamese input is available today with zero licence acceptance: **Qwen3Guard-Gen-0.6B** (open weights, Apache 2.0, fits in 8GB VRAM without quantization) or `omni-moderation-latest` (free API, no data-licence gate, needs only an OpenAI API key — a commercial account, not a content-licence acceptance) or Azure AI Content Safety (per wave 2b, lists Vietnamese as "Supported") as the guardrail(s) under test; **ViHOS** or **MultiJail** or the **SEA-HELM `vi_general.jsonl`/`en_general.jsonl` pair** as the Vietnamese test corpus (this wave); **Helsinki-NLP/opus-mt-vi-en** + **opus-mt-en-vi** as the free local translation path if a machine-translated English control arm is wanted (MultiJail and the SEA-HELM pair already ship native/existing English controls, so translation is only needed if ViHOS is the chosen corpus).
