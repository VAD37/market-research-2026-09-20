## The rDNS finding, stated plainly

Google documents a four-step forward-confirmed reverse-DNS procedure (`host <ip>` → check domain is `googlebot.com`/`google.com`/`googleusercontent.com` → forward lookup → confirm match) and recommends it as an alternative to IP-range matching. **That procedure only works for Google.** Measured this pass: sampled OpenAI IPs (GPTBot, SearchBot, AdsBot) return no PTR record at all against a public resolver (8.8.8.8); sampled Anthropic and Perplexity IPs resolve to generic cloud-vendor rDNS (`bc.googleusercontent.com`, `compute-1.amazonaws.com`, `us-east-2.compute.amazonaws.com`) indistinguishable from any other tenant of that cloud account. Common Crawl is the one non-Google exception with a vanity rDNS convention (`*.crawl.commoncrawl.org`).

**Consequence for detection design:** a domain owner cannot use rDNS to verify OpenAI, Anthropic or Perplexity fetches. The only workable method for those three is matching source IP against the published JSON range files — which means the detector must re-fetch those files on a cache-refresh cycle short enough to catch changes (OAI's `chatgpt-user.json` regenerates within hours; `gptbot.json` has not moved since 2025-10-30 — refresh cadence differs per file, not stated by any vendor, inferred from `creationTime` deltas, measured-by-us).

## The counter-finding that limits everything above (carried from pass 2, unchanged)

Cloudflare's Aug-2025 test found Perplexity running an **undeclared** crawler — generic Chrome-macOS UA, IPs outside the published range, rotating IPs and ASNs to evade robots.txt blocks — generating 3-6M daily requests against 20-25M declared. Declared-identity detection (UA, IP list, rDNS, ASN) catches the compliant majority and, on this one documented case, misses a meaningful minority. No equivalent test of OpenAI's or Anthropic's compliance was found, cited, or attempted this pass.

## Caveats

- ASN and rDNS samples are small (2-3 IPs per engine, not the full published range). A larger sample was out of scope for this pass's time budget.
- ip-api.com is a free, unauthenticated, best-effort geolocation/ASN service — not a WHOIS-of-record. Treated as measured-by-us but not authoritative; a RIR WHOIS query (ARIN/RIPE) would be the stronger source, not run this pass.
- CCBot and Perplexity's numeric proximity inside AWS's `18.97.0.0/16` block is noted, not concluded — see `raw/crawler-ip-ranges-2026-09-17.md` for the full caveat.
- Bing/Copilot, Meta, Amazon, Bytespider rows are largely carried from pass 2 or marked unknown; this pass's fresh measurement effort went to OpenAI/Anthropic/Perplexity/Google/CommonCrawl, the engines with a fetchable IP-range file.
