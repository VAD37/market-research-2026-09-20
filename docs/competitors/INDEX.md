## Reading the board

Nine acquisitions in `ai-attack-defense`, two in `agent-dashboard`, none yet in `ai-search-ads`. Product lanes exit by acquisition. The services rows at the bottom are the only ones no acquirer has touched.

Deal values: only Protect AI's $634.5M is SEC-filed. Pass 2 read the actual filings for four more — Cisco's 8-K, CrowdStrike's 8-K, Check Point's 6-K and F5's 8-K all **confirm the acquisitions and state no dollar figure at all**. Every other number on this board is press-reported. Cato/Aim and Cranium/AIceberg remain unconfirmed against any primary.
